# Brand asset sources

The contribution tiles use official brand artwork on a neutral white canvas. Each tile in the profile links to a public, merged pull request authored by `ayushozha`.

| Asset | Official source | Contribution |
| --- | --- | --- |
| Wasmer | [wasmerio/wasmer logo](https://raw.githubusercontent.com/wasmerio/wasmer/main/assets/logo.svg) | [anybuild #119](https://github.com/wasmerio/anybuild/pull/119) |
| TensorFlow | [TensorFlow site logo](https://www.gstatic.com/devrel-devsite/prod/vfdb441d2e08dbd9d3e48d8cd72b242388a87bcf7626bf5fb9df50c2bdd4a70fd/tensorflow/images/lockup.svg) | [tensorflow #109358](https://github.com/tensorflow/tensorflow/pull/109358) |
| Microsoft | [Microsoft Learn symbol](https://learn.microsoft.com/en-us/entra/identity-platform/media/howto-add-branding-in-apps/ms-symbollockup_mssymbol_19.svg), accompanied by a plain-text company label | [Playwright #40064](https://github.com/microsoft/playwright/pull/40064) |
| NVIDIA | Official inline logo from the [NVIDIA homepage](https://www.nvidia.com/en-us/), retaining the eye and wordmark together | [tiny-cuda-nn #535](https://github.com/NVlabs/tiny-cuda-nn/pull/535) |

The marks belong to their respective owners. These links document open-source contributions; they do not imply employment or endorsement.

The header and six project illustrations are original vector artwork for this profile. They illustrate project concepts and are not application screenshots.
